# Learning notes

Your space for understanding what you are building. Different from the rest of
`docs/`:

- `docs/experiment_plan.md`, `deviation_log.md`, `run_log.md` are the FORMAL
  record. They are part of the submission and they are written for an examiner.
- `docs/learning/` is for YOU. Plain-language explanations you can fact-check
  against the code and against the papers, so that nothing in this project is
  a black box you cannot defend in the viva.

Each note explains one thing, points at the exact file or paper you can check
it against, and ends with a question you should be able to answer. When you can
answer it in your own words, you understand that piece.

Nothing here is marked. Being wrong in here is how you get right for the viva.
